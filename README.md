# Abdelhak Haddani — Portfolio & Resume

Personal portfolio and resume website for **Abdelhak Haddani**, CAD Drafter &amp; 3D Visualization Designer.

## Sections

- Hero introduction with typing effect
- About me
- Skills & tools (CAD/BIM, 3D visualization, design software)
- Portfolio gallery of architectural renderings
- Career experience timeline
- Education & certifications
- Contact info + downloadable resume (PDF)

## Tech

Plain HTML5, CSS3, and vanilla JavaScript — no build step required.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deploy

This is a static site — deploy as-is with GitHub Pages, Netlify, or Vercel.
